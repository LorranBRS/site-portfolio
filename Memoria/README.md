# Memoria do projeto Site Portfolio

Diario escrito do projeto, passo a passo.

## Regra

- Toda modificacao vira um arquivo **novo** nesta pasta: `AAAA-MM-DD_NNN_titulo.md`
  (NNN = numero sequencial do dia, ex.: `2026-11-09_001_inicio.md`).
- Nunca reescrever um arquivo antigo: se algo mudou, criar um novo explicando o que mudou e por que.
- Ao consultar a memoria, ler no maximo os **5 ultimos** arquivos; abrir os anteriores so se precisar.
